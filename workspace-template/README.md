# Vexa knowledge graph

An Open Knowledge Format (OKF v0.1) bundle maintained by the Vexa agent from the owner's meeting transcripts, delivered by obsidian-vexa-bridge in graph mode. The `Vexa/` folder in the owner's Obsidian vault is a fast-forward mirror of this repository: read it, link into it from your own notes, and change it by talking to the agent rather than editing files here.

- Entities: `kg/entities/<type>/<slug>.md` (person, company, project, meeting, decision, topic); indexes in each folder.
- Inbox: `uploads/` (new transcripts), `uploads/processed/` (folded).
- Change log: `log.md`.
- Conventions the agent follows: `CLAUDE.md`; the routine it runs: `agents/meeting-to-graph.md`.
- Obsidian dashboards (Dataview): `Dashboards/`.
